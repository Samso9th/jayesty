# JayEsty 26: an invitation in motion

A continuous scroll-driven wedding story for Esther and Johnmark, 30 October 2026, Abuja.

Run `npm install` and `npm run dev`. Build with `npm run build`.

The active experience is `src/journey.js` and `src/journey.css`. It uses GSAP ScrollTrigger and a Three.js camera travelling through framed photos, gold arches, petals, and interlocking rings. An opening envelope starts the story and original theme song. Scroll to move forwards or backwards; chapter controls and a wedding-details shortcut are always available. Reduced-motion mode keeps the camera stationary and changes scenes with fades.

The venue links use the reference website's published address. Replace them with a confirmed venue pin before launch. Photos and audio are in `public/assets/`. Earlier design studies remain in `src/main.js` and `src/style.css` but are not loaded by the active site.
